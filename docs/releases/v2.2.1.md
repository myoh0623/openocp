## Download

Download an installer from **Assets** below. No GitHub account or sign-in is required.

- **macOS, Apple Silicon and Intel:** `Remote-OCP-macOS-universal.dmg`
- **Windows x64:** `Remote-OCP-Windows-x64-setup.exe` or `Remote-OCP-Windows-x64.msi`
- `SHA256SUMS.txt` contains checksums for all three installers.

## New in 2.2.1

- This reissued 2.2.1 consolidates the setup tutorial, Windows terminal console fix, and updated macOS Dock icon. Download the installers again if you installed the earlier 2.2.1 build. The interim 2.2.2 release has been withdrawn; Windows users who installed 2.2.2 must uninstall it before installing this lower-numbered version.
- A four-step English/Korean setup tutorial helps new users find their RHTLC URL, workstation hostname, and dashboard address in ROL and their course book.
- Reopen the tutorial from the sidebar's **Setup tutorial** button. Review and save at the end; closing it leaves existing settings unchanged.
- Skip unavailable addresses and save an incomplete profile. Connecting remains disabled until a valid connection address is supplied.
- New profiles use `workstation.lab.example.com` and `/home/student` as editable defaults. Existing saved hostnames and explicitly empty or custom folders are preserved.
- The Windows PowerShell fallback now creates a console with working standard input, output, and error handles instead of inheriting redirected NUL or pipe handles. Unicode paths, quoting, and launcher-error reporting are preserved. A Windows regression test covers native console programs launched from both NUL-connected and pipe-connected parents.
- The macOS app icon uses a large red logo on a rounded dark tile with transparent outer corners, replacing the square artwork that appeared inside an extra gray Dock frame.

The console patch addresses a possible cause of the reported RHTLC terminal stall after password entry. Confirmation on the originally affected Windows PC is still needed. See [PR #7](https://github.com/myoh0623/openocp/pull/7) and [issue #6](https://github.com/myoh0623/openocp/issues/6).

Full RHTLC URLs, including tokens, are saved locally with profiles; passwords and private-key passphrases are not saved. The tutorial masks the token in its review and does not start a connection automatically.

These installers are not code-signed or notarized. See the [English guide](https://github.com/myoh0623/openocp/blob/v2.2.1/README.md) or [한국어 사용 안내](https://github.com/myoh0623/openocp/blob/v2.2.1/README.ko.md) for installation requirements and setup instructions.

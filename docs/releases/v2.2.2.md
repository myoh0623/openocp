## Download

Download an installer from **Assets** below. No GitHub account or sign-in is required.

- **macOS, Apple Silicon and Intel:** `Remote-OCP-macOS-universal.dmg`
- **Windows x64:** `Remote-OCP-Windows-x64-setup.exe` or `Remote-OCP-Windows-x64.msi`
- `SHA256SUMS.txt` contains checksums for all three installers.

## Fixed in 2.2.2

- Fix the Windows PowerShell fallback used when Windows Terminal is unavailable. PowerShell now receives standard input, output, and error handles from its new console instead of inheriting redirected NUL or pipe handles from the app.
- Preserve Unicode paths and quoting when launching the interactive SSH command, and retain immediate and later launcher-error reporting.
- Add a Windows regression test that verifies real console input/output for native programs launched through PowerShell from both NUL-connected and pipe-connected parents.

This release includes the complete 2.2.1 setup tutorial: four English/Korean steps, a sidebar button to reopen it, optional steps and draft profiles, and editable `workstation.lab.example.com` and `/home/student` defaults.

The console patch addresses a possible cause of the reported RHTLC terminal stall after password entry. Confirmation on the originally affected Windows PC is still needed; it does not establish that the Windows version alone caused that report. See [PR #7](https://github.com/myoh0623/openocp/pull/7) and [issue #6](https://github.com/myoh0623/openocp/issues/6).

Install 2.2.2 to receive both the tutorial and terminal fix. The already-published 2.2.1 assets remain unchanged.

Full RHTLC URLs, including tokens, are saved locally with profiles; passwords and private-key passphrases are not saved. These installers are not code-signed or notarized. See the [English guide](https://github.com/myoh0623/openocp/blob/v2.2.2/README.md) or [한국어 사용 안내](https://github.com/myoh0623/openocp/blob/v2.2.2/README.ko.md) for setup instructions.

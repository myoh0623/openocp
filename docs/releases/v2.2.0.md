## Download

Download an installer from **Assets** below. No GitHub account or sign-in is required.

| Platform | Installer |
| --- | --- |
| macOS, Apple Silicon and Intel | `Remote-OCP-macOS-universal.dmg` |
| Windows x64 | `Remote-OCP-Windows-x64-setup.exe` or `Remote-OCP-Windows-x64.msi` |

`SHA256SUMS.txt` contains checksums for the three installers. The source-code archives are for developers, not desktop installation.

## Included in 2.2

- Connect to OpenShift and RHOAI labs through IP/SSH or an RHTLC URL.
- Use the bundled RHTLC transport without installing a VPN or the official client.
- Open isolated Chrome, Chromium, or Edge sessions with the lab proxy applied.
- Launch native terminals and VS Code Remote - SSH using the same connection.
- Check required tools and show installation guidance before launching them.
- Switch the app between English and Korean.
- Save IP addresses and full RHTLC URLs in connection profiles and restore them after restarting.
- Open the project on GitHub directly from the app sidebar.

Full RHTLC URLs, including their tokens, are saved locally with profiles. Passwords and private-key passphrases are not saved. Replace saved URLs when the lab issues a new or expired address.

## Requirements

Dashboard access requires Chrome, Chromium, or Edge. Windows terminal access requires OpenSSH Client. VS Code access requires stable VS Code and Microsoft's Remote - SSH extension.

These installers are not code-signed or notarized, so macOS or Windows may show a publisher/security warning. Linux installers are not included.

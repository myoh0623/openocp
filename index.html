Open your course in ROL, select Lab Environment (or Labs on a class dashboard), and look for Copy RHTLC URL in your lab controls once the lab is running.

Open rol.redhat.com ↗

Use an SSH IP address reachable from this computer. ROL's SSH private key & instructions may describe a jump host; that public jump-host IP is not the lab workstation. Use RHTLC for the guided lab setup if a jump host is required.

Enter your password or private key in Connection settings after completing this tutorial.

In the course's introduction, find the lab environment or machine table. Use the workstation hostname listed there. In its web console, hostname -f also shows the full name. workstation.lab.example.com is an example; use your course's value.

Only Terminal and VS Code need this host. Leave it blank for dashboard access only. Use the SSH account from your course; many labs use student on port 22.

Terminal and VS Code use the IP, user, and port from step 1.

Find the OpenShift web console or OpenShift AI URL in the course's lab introduction or exercise instructions. You can also copy it from the browser inside the workstation web console. This is the lab dashboard URL, not the ROL course URL.

If OpenShift AI is installed, open it from the OpenShift console's application launcher and copy its URL. Dashboard availability and addresses depend on the course.
